# calculator1

Простой калькулятор на C#


Простой консольный калькулятор, написанный на C#, который выполняет основные арифметические операции.

🚀 Возможности

· ➕ Сложение - сложение двух чисел
· ➖ Вычитание - вычитание второго числа из первого
· ✖️ Умножение - умножение двух чисел
· ➗ Деление - деление первого числа на второе (с проверкой деления на ноль)
· 🔄 Интерактивный режим - непрерывная работа до явного выхода
· ⚠️ Обработка ошибок - защита от некорректного ввода

📥 Установка и запуск

Способ 1: Через Visual Studio (рекомендуется)

1. Установите Visual Studio Community (бесплатно)
   · Скачайте с официального сайта
   · При установке отметьте галочку ".NET desktop development"
2. Создайте проект
   · Запустите Visual Studio
   · Выберите "Create a new project"
   · Выберите "Console App (.NET)"
   · Назовите проект SimpleCalculator
3. Добавьте код
   · Замените содержимое файла Program.cs на код калькулятора
   · Нажмите F5 для запуска

Способ 2: Через командную строку
# Создать новый проект
dotnet new console -n SimpleCalculator
cd SimpleCalculator

# Заменить содержимое Program.cs на код калькулятора

# Запустить программу
dotnet run

🎮 Как пользоваться

1. Запустите программу
2. Выберите операцию из меню (1-5):
   · 1 - Сложение
   · 2 - Вычитание
   · 3 - Умножение
   · 4 - Деление
   · 5 - Выход
3. Введите два числа когда программа попросит
4. Увидите результат операции
5. Программа продолжит работу пока не выберете "5"

📝 Пример использования
Простой калькулятор
===================

Выберите операцию:
1. Сложение (+)
2. Вычитание (-)
3. Умножение (*)
4. Деление (/)
5. Выход

Ваш выбор (1-5): 1
Введите первое число: 10
Введите второе число: 5
Результат: 10 + 5 = 15
